# SOHO — Art Direction Board

## Direction

**Premium White Ceramic 3D + Controlled Chromatic Gradients.**

SOHO visuals should feel like useful marketing systems made physical: white ceramic objects, soft studio light, a calm ink/white field, and one intentional orange–coral–violet signal. The visual is a supporting device, never the primary carrier of claims, navigation or CTAs.

## Non-negotiables

- Keep the current SOHO logo untouched. No replacement mark or speculative logo concept enters production.
- Reuse the material cues established by `public/decor/`: soft white objects, subtle warm shadow, generous empty space.
- Keep the existing token system: `#F26522` orange, `#6D28D9` violet, `#EC4899` coral only as a gradient/image accent, and `#141218` ink.
- Keep Bricolage Grotesque and Plus Jakarta Sans; image assets must not embed headings, CTA copy, client names or performance claims.
- Do not apply chrome, glass, lens flare or rainbow gradients as a default visual language. The translucent hero step cards are a UI exception, not an asset style.

## Material and composition recipe

| Element | Rule |
| --- | --- |
| Base material | Matte/off-white ceramic, soft bevels, no metallic/chrome finish |
| Lighting | Diffused upper-left studio light; one low-opacity contact shadow; no hard black cast shadow |
| Gradient | A single controlled orange → coral → violet trail, reflection or light beam; occupy less than one-third of the object/image |
| Background | Transparent or white/soft-canvas; dark use reserved for CTA/social contexts |
| Density | One hero object or 1–3 linked service objects; no icon collage |
| Depth | Moderate; clean silhouettes remain legible at a 72px service-card rendering |
| Text in image | None, except a legally required brand mark in an approved real project photograph |

## Component-specific direction

| Surface | Direction | Avoid |
| --- | --- | --- |
| Hero desktop | A right-weighted ceramic route or stepped orbit that visually echoes attract → consider → convert; leave safe space for journey cards | Full-bleed hero image; visual chart replacement; text baked into art |
| Hero mobile | A vertically compact route/goal object beneath or after copy; conceal if it competes with journey | Cropped desktop asset; tiny unreadable detail |
| Service cards | Single recognizable ceramic object on transparent/white field, emitted signal optional | Large scenes, shadows beyond art box, illustration taller than 96px |
| Portfolio | Real photography first; brand frame generated by CSS/HTML | AI “mock projects”, fake product shots, baked KPIs |
| Blog | Topic metaphor from the subject system, held in the right/central visual field with generous safe cropping | Repeated generic laptop/rocket imagery, editorial titles inside bitmap |
| CTA | Existing CSS gradient remains enough; an optional ceramic compass/path only after test | Decorative art that pushes the form below the fold |

## Accessibility and technical direction

- Decorative art: empty alt text and `aria-hidden` at the wrapper where appropriate.
- Informational process/journey: React/SVG plus semantic HTML; do not rasterize.
- Export vector illustrations as sanitized SVG; use WebP for photographic/3D raster output. Do not ship PNG where transparency is not needed.
- Define `width` and `height` (or aspect ratio) before loading. Preserve reduced-motion preferences for any animation.
- Ensure all meaningful text and indicators remain HTML/SVG with token-based contrast, not within a bitmap.
