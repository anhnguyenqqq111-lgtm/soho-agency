# GrowthLab — Next.js Vietnamese Agency Homepage

Giao diện Next.js được dựng lại dựa trên cấu trúc/trải nghiệm của HTML tham chiếu, nhưng đã:
- Bỏ logo, chứng chỉ, award, logo khách hàng, hình nhân sự và ảnh nhận diện của WebFX.
- Không hotlink tài nguyên hình ảnh từ WebFX.
- Viết lại nội dung bằng tiếng Việt tự nhiên cho agency SEO / Ads / Digital Marketing.
- Không sử dụng các số liệu thành tích/case study của WebFX.
- Responsive desktop / tablet / mobile.

## Chạy project
```bash
npm install
npm run dev
```
Mở http://localhost:3000

## Lưu ý
Tên GrowthLab, email và các nội dung kết quả là placeholder. Hãy thay bằng thương hiệu và dữ liệu thật trước khi xuất bản.
